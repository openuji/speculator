# Apps

This directory contains the applications and examples powered by Speculator.

## Projects

- **[astro-demo](./astro-demo)**: The Speculator Studio Theme and showcase application. It demonstrates features like workspace isolation, artifact generation, and theming with Astro.
- **[docs](./docs)**: The official documentation site for Speculator, built with Starlight.
- `spec-editor-example`: Vite/React shell integrating `<SpecEditor>`
- `solospec-example`: Vite shell demonstrating `@openuji/solospec` single-document publishing
