User Journey Map Core Vocabulary

Core vocabulary for defining user journey maps in a structured, machine-readable format. Enables semantic representation of user journeys, steps, and transitions.

Editor's Draft Last Updated: 2025-12-23 Namespace: http://localhost:4321/vocab/ns#

Classes

Term Label Description
Journey
http://localhost:4321/vocab/ns#Journey copy
Journey A complete user journey consisting of multiple steps and transitions. Represents the overall flow of a user's interaction with a system or service.
Step
http://localhost:4321/vocab/ns#Step copy
Step A single step or touchpoint in a user journey. Represents a discrete action, state, or interaction point that a user experiences.
Transition
http://localhost:4321/vocab/ns#Transition copy
Transition A transition between two steps in a journey. Defines the flow and connection between different user journey steps.
