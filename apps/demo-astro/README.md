# Speculator Studio Theme (`apps/astro-demo`)

> [!WARNING]  
> This demo is still WIP, it will change.

Astro showcase app for the Speculator ecosystem with:

- Two isolated workspaces (`ed-clean`, `ed-to-lint`)
- Build-time lint/search/vocab artifact generation
- Token-driven theming (Tailwind v4)
- Global header search modal (`Cmd/Ctrl+K`)
- Breadcrumb + previous/next spec navigation on document pages
- Mermaid and LikeC4 diagram rendering

## Quick start

```bash
pnpm install
pnpm --filter apps-astro-demo dev
```

This app generates required artifacts before `dev` and `build` via `predev` / `prebuild`.

`SPEC_BASE_URL` is optional. If not set, local builds default to `http://localhost:4321`.
You can set it in `apps/astro-demo/.env` (or `.env.local`).

## Commands

```bash
pnpm --filter apps-astro-demo artifacts:build
pnpm --filter apps-astro-demo search:build
pnpm --filter apps-astro-demo vocab:build
pnpm --filter apps-astro-demo check
pnpm --filter apps-astro-demo build
```

## Workspace showcase

Routes:

- `/workspaces` - workspace hub, document list, lint summary, artifact links
- `/workspaces/[workspace]/[doc]` - rendered spec document

Workspace configuration lives in `speculator.workspace.json`:

- `ed-clean` uses directory shorthand discovery.
- `ed-to-lint` uses explicit entry definitions.

Corpus lives in `src/spec/workspaces/` with mixed Markdown/HTML entries, include directives, and cross-document dependencies.

Single-document pages include:

- breadcrumb path back to workspace overview
- previous/next document navigation within the current workspace

## Search modal

Global header search is always available:

- Focus header input to open modal
- Press `Cmd+K` / `Ctrl+K` to open modal globally
- Results are weighted/ranked from `public/search-index.json`

Search index is generated by `scripts/build-search-index.mjs` using `@openuji/speculator-search`.
The script also reads `apps/astro-demo/.env` / `.env.local` for `SPEC_BASE_URL`.

## Diagram rendering

- Mermaid diagrams render from markdown code blocks with `mermaid` language.
- LikeC4 diagrams render from `<likec4-view view-id="...">` blocks using the LikeC4 Vite plugin.

## Vocabulary outputs

Vocab sources:

- `core` module is derived from spec definitions (`document.indexes.definitions`) in workspace docs that reference `core` and do not have workspace build errors.
- `ui` module comes from `vocab/ed-ui.jsonld` (supports `SPEC_*` placeholders).

Vocab build script:

- `scripts/build-vocab.mjs`
- derives required vocab modules from workspace document config (`custom.vocabModules`)
- loads `apps/astro-demo/.env` and `.env.local` explicitly, then applies process env overrides
- interpolates `SPEC_*` values for file-backed modules (for example `ui`)
- validates namespace/docBase consistency before building

Generated outputs:

- `/vocab/ns/index.html`
- `/vocab/ui/index.html`
- `/vocab/contexts/core.jsonld`
- `/vocab/contexts/ui.jsonld`

## Tailwind v4 theming without CSS edits

Theme tokens are configured in code, not selectors.

1. Open `src/theme/site.ts`
2. Change `site.themePreset` (for example: `studio`, `contrast`, `paper`)
3. Adjust token values in `src/theme/tokens.ts` if needed

`src/styles/theme.css` stays semantic and maps token variables into Tailwind v4 via `@theme inline`.
